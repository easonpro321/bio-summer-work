# Biology Term Scavenger Hunt

**One file. `index.html`. That's the whole thing.**

It is both your workspace and the finished site. Delete any older files —
`edit.html`, `terms.js` — you don't need them.

---

## Working on it

Double-click `index.html`. You'll see 50 sheets and an **Edit** button near the title.

Click **Edit**. A toolbar appears at the top. Now click any sheet to open it, and you can:

- Drop a photo in, or tap the box to pick one
- Type your caption — a counter tracks sentences so you can see when you hit five
- Rename the term if you're swapping one out
- Move around with the arrow buttons, or left/right arrow keys

Everything saves as you type. Click **Done editing** to see it the way your teacher will.

Sheets are dashed while empty, tan-edged when they have a photo *or* a caption but not both,
and solid once finished. The bar of 50 marks under the title tracks the same thing.

Set your name and identifier once, from the toolbar.

**Your work lives in this browser only.** Hit **Save backup** at the end of each session —
it downloads a file you can reload later with **Load backup**. If you shoot on your phone
and write on your laptop, carry that backup file across. They don't sync.

Photos are resized automatically, so a big phone photo becomes a few hundred KB. Don't
bother shrinking anything first.

---

## Publishing

**Setup, once:**

1. github.com → **New repository** → name it `ap-bio-scavenger-hunt` → **Public** → Create.
2. In the editor, click **Export site**. You get `apbio-site.zip`. Unzip it.
3. On GitHub, click **uploading an existing file**. Drag in `index.html` and the `images`
   folder from the unzipped export. Commit.
4. **Settings** → **Pages** → Source **Deploy from a branch**, branch **main**, folder **/ (root)** → Save.
5. Wait a minute, refresh. Your link is at the top:
   `https://YOURUSERNAME.github.io/ap-bio-scavenger-hunt/`

That link is what you submit.

**Every time after:** export again, upload the new `index.html` and `images` over the old
ones. GitHub redeploys in about a minute.

The published page opens in view mode for anyone visiting. The Edit button is still there
for you — visitors have no saved work, so they only ever see the finished collection.
You can also jump straight to editing by adding `#edit` to the end of your link.

---

## Before you submit

- Open the link in a private window to check it's really public
- Counter reads 50 of 50
- Name and identifier are set
- Identifier visible in every photo
- No specimen used twice
- Every caption five sentences, your own words
